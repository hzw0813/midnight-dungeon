# 深夜地牢 · Midnight Dungeon v0.5 — Impact Edition

**手機遊玩：** https://hzw0813.github.io/midnight-dungeon/

免費、單檔 HTML5 回合制 Roguelite。用手機方向鍵或在地圖上滑動移動；往怪物方向移動就是攻擊。不需要登入或安裝。

## v0.5：戰鬥與獎勵回饋

- 敵人扣血顯示傷害浮字；暴擊有金色較大浮字、短暫光圈與亮度回饋。
- 怪物、精英與 Boss 擊殺分別提示；金幣、魂晶、回血、受傷與升級都有不同顏色。
- 精英遠古聖物匣改為金色邊框的獎勵面板，傳說聖物卡片出現一次掃光動畫。
- 動效自動清理（最多 40 個節點）、不攔截 Canvas 觸控，支援系統「減少動態效果」。
- 本次不改動傷害、怪物能力、抽獎機率或 RNG；特效只看遊戲操作前後差異，不修改存檔或重播結果。

## 保留的系統

無盡樓層、打怪 XP、升級、金幣與鍛造、每層祝福、六種可疊聖物及流派連攜、每五層 Boss、偶數非 Boss 層精英與稀有寶箱、死亡後永久魂晶與天賦。

## 進度保存

網站使用 localStorage。新 key 為 `midnight-dungeon-v0.5`，若無 v0.5 存檔會依序從 v0.4、v0.3、v0.2、v0.1 的有效存檔轉換；舊 key 原樣保留。不同瀏覽器無法自動同步，請勿隨意清除 Safari 網站資料。

## 專案與測試

`index.html` 是完整遊戲；`PROJECT_STATE.md` 是跨聊天交接；`TEST_REPORT.md` 是測試結果。`test_regression.py` 提供核心回歸冒煙測試，`test_visual_fx.py` 提供動效煙霧測試。完整 1,114 項引擎斷言與 13 項新動效斷言的測試腳本、截圖與紀錄可從本次 v0.5 ZIP 取得。

目前通過 Chromium 手機模擬測試，**實體 iPhone Safari 尚未驗收**。
