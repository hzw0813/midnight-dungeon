# 深夜地牢 / Midnight Dungeon v0.5.1 — 打擊感修正

**手機遊玩：** https://hzw0813.github.io/midnight-dungeon/

## 為什麼更新
使用者回報 v0.5 攻擊時看不出閃光。檢查後確認原本正常攻擊只有小浮字，僅暴擊短暫提升地圖亮度；此外，iPhone 開啟「減少動態效果」時，舊程式會直接取消浮字顯示。

## v0.5.1 修正
- **普通攻擊命中：** 地圖短暫綠色亮光、明亮描邊、擊中光圈以及實際傷害數字。
- **暴擊：** 金色地圖亮光與描邊、較大的傷害數字。不是整個手機螢幕快速閃白。
- **減少動態效果：** 不播動畫，改為短暫顯示靜態傷害數字。
- 地圖下方加入 **「試播打擊特效」**，先展示普通命中（綠光、−8），再展示暴擊（金光、✦ −16）。不耗回合、不改變 HP、RNG、金幣或存檔。
- 定時清除暫時 DOM 特效，降低 Safari 動畫結束事件可能未觸發時的累積風險。
- 新存檔 key `midnight-dungeon-v0.5.1`；會自動從 v0.5、v0.4、v0.3、v0.2、v0.1 有效存檔遷移，舊 key 不刪除。

## iPhone Safari 驗收
1. 進入網站確認標題下方顯示 **V0.5.1**。
2. 滑到操作區下方，點 **「試播打擊特效」**，應看到地圖短暫綠光再金光，並有傷害數字。
3. 往怪物方向移動實際命中，也應看到傷害浮字及地圖亮光。
4. 重新整理確認原有魂晶、聖物、等級和進度保留。
5. 如果只看到**靜態**數字，可能已啟用 iPhone「設定 → 輔助使用 → 動態效果 → 減少動態效果」。這是預期的無動畫呈現。
6. 如果仍顯示 V0.5，請重新整理或關閉舊分頁後再開，不要直接清除網站資料，以免本機存檔消失。
