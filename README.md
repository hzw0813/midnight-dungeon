# 深夜地牢 / Midnight Dungeon — v0.5.2 Clear Combat

**遊玩網址**：https://hzw0813.github.io/midnight-dungeon/

這次是修復使用者回報「懸浮文字會擋住角色跟怪物」的介面更新。

## 修正內容
- 所有傷害、暴擊、擊殺、金幣、魂晶、回血與升級文字，統一顯示在**地圖下方獨立戰鬥回饋列**，不再重疊角色／怪物／血條。
- 地圖上只顯示短暫的透明中心命中光圈，保留普通攻擊綠光和暴擊金光；光效不攔截觸控。
- 戰鬥文字最多 3 個標籤（螢幕寬度小於 360px 時 2 個），自動清除，長字會截斷避免橫向溢出。
- 「試播打擊特效」按鈕不消耗回合、亂數或存檔。
- iPhone「減少動態效果」開啟時，文字仍以靜態方式顯示在下方。
- 不改動傷害、怪物、掉落率、樓層、成長或重播規則。

## iPhone 驗收
1. 開啟網站，確認標題下方為 V0.5.2。
2. 點「試播打擊特效」：地圖亮綠光、再亮金光；兩個傷害數字只應出現在地圖下方。
3. 實際攻擊怪物：角色、怪物與血條應保持可見。
4. 重新整理後確認原有魂晶、聖物、樓層與永久天賦保留。
