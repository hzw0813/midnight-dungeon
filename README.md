# 深夜地牢 / Midnight Dungeon — v0.3 聖物覺醒

遊戲：https://hzw0813.github.io/midnight-dungeon/

單檔 HTML5 回合制無盡地牢，可用 iPhone Safari 觸控操作。不需要帳號、外部套件或付費。透過擊殺獲得 XP 與金幣，升級、鍛造及補藥；每層有三選一祝福，每 5 層有守衛；返回營地以魂晶購買永久天賦。

## v0.3 新增
- **◆ 聖物背包**：第 1、4、7、10… 層通關後，選完祝福，再從 3 件聖物中選 1 件。相同聖物可堆疊升級。
- **普通** 回聲之刃：每第三次攻擊追加傷害；鍊金錢袋：擊殺增加金幣，搭配貪婪祝福回血。
- **稀有** 緋月徽記：擊殺回血，搭配吸血祝福更強；雷霆護符：暴擊率增加，暴擊雷鏈傷害附近另一敵人；荊棘胸針：受擊反傷，反殺可取得 XP。
- **傳說** 不滅火種：每層首次受到致命傷害時重生，下層可再次觸發。
- 戰鬥訊息支援雷鏈、回聲、荊棘反傷與火種重生提示，選擇面板以稀有度區分。

## 舊版存檔
新版使用 `midnight-dungeon-v0.3`。首次載入會自動嘗試保留 v0.2 的完整進度、魂晶與天賦，亦可由有效 v0.1 存檔遷移。舊 key 保留，不會刪除。localStorage 是本機資料，不能跨瀏覽器同步；遷移後舊行動序列也不一定適用新版重播規則。

## 開發／測試
`index.html`：完整遊戲、無需 build；`PROJECT_STATE.md`：跨聊天交接；`TEST_REPORT.md`：測試摘要；`test_regression.py`：Chromium 自動回歸冒煙測試。完整測試與手機模擬截圖也包含在 v0.3 ZIP。尚待真實 iPhone Safari 驗收。
