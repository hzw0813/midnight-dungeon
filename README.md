# 深夜地牢 — v0.4 精英狩獵
遊玩：https://hzw0813.github.io/midnight-dungeon/

單檔 HTML5 手機回合制 Roguelite，使用方向鍵或在地圖上滑動移動；走向怪物會攻擊。

## 成長循環
擊殺獲得 XP/金幣，升級與鍛造；每層有祝福三選一，第 1、4、7、10… 層可獲得聖物三選一，每五層需擊敗 Boss 才能通關。回營地後使用魂晶提升永久天賦。

## v0.4 精英
偶數樓層（守衛關除外）會出現 1 隻精英：**重槌狂徒**先蓄力再雙倍重擊，可以閃避；**鐵甲守衛**首次受傷格擋最多 2 點；**疾影獵手**遠距離一回合可走兩格。精英額外給 3 XP，擊敗後一定掉寶箱，須走上寶箱所在格領取。

- 黃金寶箱 52%：8＋2×當前樓層金幣、藥水 1。
- 魂晶寶箱 30%：永久魂晶 2、藥水 1。
- 遠古聖物匣 18%：額外聖物三選一，選擇期間戰鬥暫停。

## 存檔
使用網站 localStorage 存檔，新 key 為 `midnight-dungeon-v0.4`，會嘗試轉換有效的 v0.3、v0.2、v0.1 進度，原版存檔 key 留作備份。不跨瀏覽器或清除網站資料後保證保留。可用「紀錄」複製 seed、操作與現在地牢狀態。

## 測試
`index.html` 是完整遊戲，不依賴外部套件；`test_regression.py` 是簡短 Playwright 回歸測試。另有本輪完整 1,114 個引擎斷言的測試腳本與手機截圖封裝於 `midnight_dungeon_v0.4.zip`。真實 iPhone Safari 尚未驗收。
